Select the requested object or visible part from SAM3 candidates on two current calibrated images.
Each image has camera name and unique numbered mask outlines. target_description identifies the parent physical object; segmentation_description is the exact high-level SAM query and specifies whether to select the whole object or a particular visible part. Preserve both identity and requested segmentation scope. Select zero or one candidate per camera depicting that SAME target. Lower SAM scores are allowed; score or being the only candidate does not prove identity. Do not sort objects programmatically by left/right; interpret the description against the original scene. A whole-object query should select the whole object; a part query should select that part of the identified object, not substitute the whole object. Never select background, an empty cavity, or a different object with similar colour.
If no candidate in a camera is correct or visible, select none for that camera. If neither image has a confident target, return an empty list. Never force a choice. Output only JSON: {"selected_ids": [<integer IDs>], "reason": "visible reason, at most 12 words"}. At most one ID per camera. These masks provide observed surface points, not a grasp pose or success certification.
